# GG Webmaster 3.0

## Vad detta är

Detta är den förbättrade versionen av GG Webmaster för Gold Goblins och [www.goldgoblins.se](http://www.goldgoblins.se).

GPT:n är byggd för att arbeta med:

* WordPress;
* BlankSlate Theme;
* WooCommerce;
* Code Snippets;
* PHP;
* HTML;
* CSS;
* JavaScript;
* AJAX och REST;
* adminverktyg;
* teknisk SEO;
* UX och konvertering;
* tillgänglighet;
* säkerhet;
* prestanda.

## Filer

### `INSTRUKTIONER.txt`

Klistra in hela innehållet i GPT-byggarens fält **Instructions**.

### `GG-WEBMASTER-KNOWLEDGE.md`

Ladda upp filen under **Knowledge**.

### Webbplatsens befintliga filer

Ladda även upp de senaste versionerna av:

* Code Snippets-exporten;
* Gold Goblins README;
* relevanta sid-HTML-filer.

Kod som uttryckligen anges som aktuell i en konversation väger tyngre än äldre exporter.

## Rekommenderat namn

**GG Webmaster**

## Rekommenderad beskrivning

> Teknisk webbansvarig för Gold Goblins. Analyserar och vidareutvecklar WordPress, WooCommerce och Code Snippets med riskstyrning, säker kod, bevarad design samt tydliga test- och rollbackplaner.

## Rekommenderade funktioner

Aktivera:

* Webbsökning
* Code Interpreter & Data Analysis
* Knowledge och filuppladdning

Aktivera endast vid konkret behov:

* Bildgenerering

Actions behövs inte i grundversionen.

## Installation

1. Öppna den befintliga GG Webmaster i GPT-byggaren.
2. Spara en kopia av de nuvarande instruktionerna.
3. Ersätt nuvarande Instructions med innehållet i `INSTRUKTIONER.txt`.
4. Ta bort eller arkivera den gamla systeminstruktionen så att den inte konkurrerar med version 3.0.
5. Ladda upp `GG-WEBMASTER-KNOWLEDGE.md`.
6. Ladda upp senaste Code Snippets-export.
7. Ladda upp relevanta sid-HTML-filer.
8. Aktivera rekommenderade funktioner.
9. Spara GPT:n som en ny version.
10. Kör första testet i Preview.

## Första test

Skriv:

> I sidovarukorgen vill jag ändra hoverfärgen på stängknappen. Ändra inget annat.

Godkänt resultat:

* uppgiften klassas som låg risk;
* GPT:n föreslår en liten isolerad CSS-ändring;
* den bygger inte om sidovarukorgen;
* eventuell hög säkerhetsrisk flaggas separat;
* den separata risken ändras inte utan godkännande;
* GPT:n säger att ändringen endast är statiskt granskad om den inte har körts.

## Vad som har förbättrats

Version 3.0 innehåller:

* tydlig källprioritet;
* riskklassning;
* påverkanskarta;
* säkerhetskontroll mot faktisk kod;
* WooCommerce HPOS- och Blocks-medvetenhet;
* tydligare gräns mellan Code Snippet och mini-plugin;
* Mandat A för närliggande höga risker;
* adaptiva svarsformat;
* tydlig test- och rollbackmodell;
* ärlig valideringsnivå.

## Begränsningar

* GPT:n har inte automatiskt tillgång till WordPress-admin eller servern.
* Statisk kodgranskning ersätter inte staging.
* WordPress-, WooCommerce- och PHP-version måste verifieras när lösningen är versionsberoende.
* De uppladdade kodexporterna är snapshots och kan vara äldre än livekoden.
* Paketet ändrar inte webbplatsen automatiskt.
